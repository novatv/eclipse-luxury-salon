# Eclipse Luxury Salon

Web y tienda de Eclipse Luxury Salon — nutrición y estilo de vida, Bilbao.

Una sola página, un solo archivo: `index.html`. Incluye el catálogo con las
fotos y los precios incrustados, el carrito y los pedidos y consultas por WhatsApp.
No necesita servidor, ni base de datos, ni dependencias.

## Publicar con GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → `main` / `root` → Save.
En un minuto la web está en `https://USUARIO.github.io/NOMBRE-DEL-REPO/`.
